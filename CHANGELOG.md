# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Fixed

- Spec descriptions: "any of the every supported platform" corrected to "any supported platform". The spec is also served at https://handlesapi.com/openapi.json.

## [1.0.0] - 2026-11-26

### Added

- OpenAPI 3.1 description of the Handles API: 113 operations, bearer and `x-api-key` authentication, the `{data, meta}` envelope, 13 stable error codes, cursor pagination, and `x-credits`, `x-live-call` and `x-scope` extensions.
- README with endpoint tables by group, Postman and Insomnia import, and code generation examples.
