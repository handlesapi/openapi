# Contributing to the Handles API OpenAPI specification

`openapi.json` is generated from the API's source of truth and published here unchanged, so a pull request that edits it by hand cannot be merged as is. Please open an issue instead, and we will fix it at the source and update this file.

## Useful reports

- A path, parameter, field or response in the spec that does not match what the live API returns (include the `request_id`).
- A description that is wrong, unclear or misspelled.
- A validation or code generator error you hit with a specific tool (include the tool and version).

## Pull requests

README changes (endpoint tables, import instructions, generator examples) are welcome as pull requests. Add a line to `CHANGELOG.md` under Unreleased.

Issues: [handlesapi/openapi/issues](https://github.com/handlesapi/openapi/issues). For account or billing questions, email support@handlesapi.com.
